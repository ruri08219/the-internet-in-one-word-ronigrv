## Entry — "yapping"

> yapping

One word, 7 characters. The whole internet in one word: everyone talking at once, endlessly, about everything. It is funny by itself, it says something true about the internet as a whole rather than one app or one mood, and it is not the first obvious word anyone reaches for — the field is flooded with "feral", "doomscroll", "brainrot" and "enshittification", while nobody entered "yapping".

## How it works

`main.py` (Python standard library only) validates the word — one word, 1–30 characters, no whitespace, no control characters — then writes it to `/output/entry.txt` with no trailing newline and verifies the round trip.
